# Дневник · SOGOMONYAN Tigran

Авторский фотодневник: выпуски, поездки, темы, заметки и архив.

**Сайт:** https://tigransogomonyan.github.io/diary/  
**Связанный проект:** https://tigransogomonyan.github.io/portfolio/

## Устройство

- `index.html` — главная, галерея, читалка выпусков, поездки, темы и архив.
- `trip/yerevan.html` — глава о поездке в Армению.
- `trip/tbilisi.html` — глава о Тбилиси; фото пока не опубликованы.
- `f/*.webp` — фотографии.
- `frames.css` и `frames.js` — галереи и подписи к кадрам.
- `improvements.css` и `improvements.js` — адаптивная навигация, редакционные детали и управление с клавиатуры.
- `site-controls.js` — ручное переключение светлой/тёмной темы (с сохранением выбора) и индикатор прогресса чтения. При первом посещении используется тема устройства.

Это статический сайт без сборки и серверной части. Для публикации используется GitHub Pages из основной ветки репозитория.

## Изменения

Работайте через отдельные ветки и Pull Request. Не заменяйте фотографии и авторские тексты служебными заглушками на публичных страницах. Новые материалы удобно добавлять в `f/`, после чего обновлять соответствующие HTML-страницы.

Перед объединением правок проверьте верстку на мобильном и десктопном экранах, читалку выпусков, переключение тем, навигацию с клавиатуры, ссылки и консоль браузера. Держите `CHANGES.md` в актуальном состоянии.
